# Changelog

## [1.2.0] - 2026-07-17

### Added

- Add `ensure-conventional-commits` action, which checks that every commit on a pull request follows the
  [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification ([#25](https://github.com/SE-UUlm/snowballr-ci/issues/25)) (Felix Schlegel)
- Add `ensure-conventional-branches` action, which checks that a branch name follows the form
  `<type>/<issue-number>-<slug>` ([#25](https://github.com/SE-UUlm/snowballr-ci/issues/25)) (Felix Schlegel)

## [1.1.0] - 2026-04-20

### Added

- Add `markdownlint-config-path` parameter to lint-md action ([#19](https://github.com/SE-UUlm/snowballr-ci/issues/19)) (Moritz Wieland)

## [1.0.0] - 2025-12-04
